## 2. 逐个文件详解

### 2.1 `src/notifier/web.py`

`render_site()` 增加参数：
```python
subfields: list[dict[str, str]] | None = None,
```

渲染时给模板传两组数据：
```python
subfields=subfields or [],                       # 渲染 chips 用（key + label 列表）
field_labels={s["key"]: s["label"] for s in (subfields or [])},   # 卡片徽章查 label 用
```

`field_labels` 是个 dict（`{key: label}`），模板里用 `field_labels[a.score.field]` 把 key 转成中文名。

### 2.2 `src/main.py`

`run_render_cmd()` 调用处加一行，把 Phase 1 解析好的 `config.subfields` 传下去：
```python
subfields=config.subfields,
```

### 2.3 `templates/index.html.j2`

**① CSS**：新增 `.field-btn`（chips 按钮）和 `.field`（卡片上的子领域徽章）样式。

**② 卡片宏**：
- `<article ... data-field="{{ a.score.field or '' }}">` —— 每张卡片带上自己的子领域 key，供 JS 筛选。
- 徽章区加一个紫色子领域徽章：
  ```jinja
  {% if a.score.field and field_labels.get(a.score.field) %}
  <span class="field" title="子领域">{{ field_labels[a.score.field] }}</span>
  {% endif %}
  ```

**③ chips 导航**（在「目录」nav 下面新增一个「子领域」nav）：
```jinja
<nav class="toc subfields" id="subfield-nav">
  <h2>子领域</h2>
  <div class="chips" id="field-chips">
    <button class="field-btn active" data-field="" onclick="filterField('')">全部 <span class="n">今日 <b class="n-today">0</b> · 归档 <b class="n-archive">0</b></span></button>
    {% for sf in subfields %}
    <button class="field-btn" data-field="{{ sf.key }}" onclick="filterField('{{ sf.key }}')">{{ sf.label }} <span class="n">今日 <b class="n-today">0</b> · 归档 <b class="n-archive">0</b></span></button>
    {% endfor %}
  </div>
</nav>
```

**④ 筛选 JS**（纯内联，零构建）：
- `filterField(field)`：记录当前 field、更新 chips 高亮、调 `applyFieldFilter()` + `refreshFavoritesSection()`。
- `applyFieldFilter()`：
  - 遍历所有卡片，`data-field` 不匹配的 `display:none`；
  - 归档里没可见卡片的 `<details>` 日期组也隐藏；
  - 「今日/归档」栏若无可见卡片，显示「该子领域暂无匹配内容」的空态提示。
- `refreshFavoritesSection()` 增加一行 `if (card.style.display === 'none') return;`，让「我的收藏」也遵循当前筛选。

**⑤ 条数徽章（今日/归档分开）**：
- 每个 chip 显示两个数：`今日 X · 归档 Y`，由 `refreshFieldCounts()` 在页面加载时**分别**统计「今日」栏和「归档」栏的卡片数量填充。
- `applyFieldFilter()` 里同步更新「今日新增 / 归档」标题上的计数 `(N)`。

## 5. 遇到的问题与解决（踩坑记录）

### 5.1 切换领域时「条数不变」
- **现象**：点某个子领域 chip，卡片确实筛选了，但 chips 和标题上的数字没变。
- **原因**：那些数字是 Jinja 在**服务端渲染时写死的静态值**（`{{ today|length }}`），而筛选是纯客户端 JS，数字自然不更新。
- **解决**：改成 JS 动态统计——`refreshFieldCounts()` 在页面加载时数卡片数量填充到 chips；`applyFieldFilter()` 每次筛选时更新标题计数。

### 5.2 归档计数一直不更新（`getElementById('archive')` 取到 null）
- **现象**：筛选后「今日新增」计数更新了，「归档」计数纹丝不动。
- **原因**：归档 `<section>` 只有 `data-band="archive"`，**没有 `id="archive"`**；JS 里 `document.getElementById('archive')` 返回 `null`，代码 `if (!sec) return;` 直接跳过，归档计数和空态提示都没执行。
- **解决**：给归档 section 补上 `id="archive"`。教训：JS 用 id 取元素前，先确认模板里该元素确实有 id。

### 5.3 子领域数量「合并」了（今日 + 归档混在一起）
- **现象**：chip 上的数字是「今日新增 + 归档」的**总数**，看不出今天和历史的分别。
- **原因**：最初 `refreshFieldCounts()` 只按 `data-field` 统计全部卡片、不区分所属栏。
- **解决**：改为**按栏分别统计**——遍历「今日」栏和「归档」栏各自的卡片，每个 chip 显示两个数：`今日 X · 归档 Y`。
