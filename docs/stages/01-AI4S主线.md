## 2. 核心设计：子领域分类（field）

**为什么要有 field？** 后续前端要做「按子领域分类导航」，需要每条内容有一个确定的分类。方案是让 **scorer（便宜 LLM）在打分时顺带输出一个 `field`**，值必须来自 `preferences.yaml` 里 `subfields` 配置的 key（8 选 1），存入 `summaries.field`。

8 个子领域（key → 界面显示名）：

| key | label |
| --- | --- |
| `protein` | 蛋白质/结构 |
| `drug` | 药物发现 |
| `molsim` | 分子模拟 |
| `materials` | 材料科学 |
| `climate` | 气候地球 |
| `ai4math` | AI4Math/PDE |
| `scifm` | 科学基础模型 |
| `bioinfo` | 生物信息 |

**防御性设计**：如果 LLM 返回了不在列表里的 field（幻觉/翻译），`summarizer.py` 会打 WARNING 并回退为 `""`（未归类），不会写脏数据。

## 3. 逐个文件详解

### 3.1 `config/preferences.yaml`

**关键词** 从 AI 方向：
```yaml
keywords: [LLM agent, MCP, tool use, RAG, multi-agent, reasoning models]
```
改为 AI4S 方向：
```yaml

  - protein structure prediction
  - molecular dynamics
  - drug discovery

```

**新增 `subfields`**（上表 8 项）。`models` 保持 Phase 0 已改好的 DeepSeek 不变。

  - `arxiv-ml`：`cs.LG / stat.ML / math.NA`（机器学习、数值分析）
- **GitHub Topic**（4 个源）：`protein-structure-prediction`、`molecular-dynamics`、`drug-discovery`、`scientific-machine-learning`
- **实验室/厂商博客**：DeepMind、Google Research、Microsoft Research、NVIDIA

### 3.5 `src/config.py`

### 3.6 `src/models.py`

### 3.7 `src/storage.py`

### 3.8 `src/summarizer.py`

## 5. 补充改动：前端 tab 切换 + 归档语义改为按日期

> 日期：2026-09-11
> 在 Phase 1 验收过程中发现两个体验问题，顺手修复并记录于此。

### 5.1 问题与动机

1. **前端是「顺序滚动」而非「切换」**：原 `index.html` 的「今日新增 / 归档」是上下堆叠的两块，顶部目录的 chips 只是锚点跳转。希望改成点按钮互斥切换（tab）。
2. **同日多次 render 会把「今日」清空**：原 `surfaced_at` 语义是「只要上墙过就进归档」，同一天第二次 render 时「今日新增」必空，演示/调试不直观。希望改为「按上墙日期判定」——今天上墙算今日，跨天才算归档。

### 5.2 改动内容

**`templates/index.html.j2` — tab 切换**

- 目录 chips 从锚点链接改成三个互斥 tab 按钮：⭐ 我的收藏 / 今日新增 / 归档。
- 三个区块加 `data-band` 标记（favorites / today / archive）。
- 新增 `switchTab(band)`：只显示目标区块、隐藏其余、高亮当前 tab。
- 页面加载时默认显示「今日新增」，若今日为空则落到「归档」。
- 「我的收藏」增加空状态文案；移除原先冗余的日期锚点快捷链接。

**`src/storage.py` — 归档语义改为按日期**

- `get_today_summaries`：条件从 `surfaced_at IS NULL` 改为 `(surfaced_at IS NULL OR surfaced_at >= 今天零点)`。
- `get_archive_summaries`：增加 `surfaced_at < 今天零点`，只归档「之前几天」上墙的内容。
- `mark_surfaced` 不变（仍只把 NULL → now，天然幂等）。

**测试同步**

- `test_storage_dedup.py`：`test_mark_surfaced_moves_items_to_archive` → `test_mark_surfaced_keeps_items_in_today_until_next_day`；`test_archive_filters_by_within_days` 改用「昨天 / 30 天前」。
- `test_notifier_web.py`：`test_render_site_second_run_same_day_moves_to_archive` → `test_render_site_keeps_today_same_day_moves_to_archive_next_day`。

## 7. 踩坑记录（疑问与解决）

### 7.1 GitHub Topic 源被限流（无 GITHUB_TOKEN）
- **现象**：4 个 `github-trending-*` 源抓不到数据（GitHub API 返回 403/429）。
- **原因**：GitHub API 匿名请求的小时配额极小，未配 token。
- **解决**：在 `.env` 里填 `GITHUB_TOKEN`（GitHub Actions 会自动注入 `secrets.GITHUB_TOKEN`），`fetch_github` 会自动带 `Authorization: Bearer` 头。

### 7.2 google-research / microsoft-research RSS 连不通
- **现象**：这两个 RSS 源在当前网络下抓不到内容。
- **解决**：属网络可达性问题，被按源隔离失败吞掉；网络允许时再启用即可，不影响主流程。

### 7.3 子领域 `field` 越界回退（防御 LLM 幻觉）
- **现象**：scorer 返回的 `field` 可能不在 `subfields` 配置里（模型翻译/幻觉/发明新 key）。
- **解决**：`_score_one()` 校验 `field` 必须 ∈ `cfg.subfields` 的 key 集合，越界则打 WARNING 并回退为 `""`（未归类），不写脏数据入库。
