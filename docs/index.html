deepmodeling/deepmd-kit

8 GitHub · MD 分子模拟
molecular-dynamicsmaterialscodefoundation-model

把「分子动力学（MD，模拟原子运动的方法）」里最耗时的原子间相互作用势，换成深度学习模型来算，精度接近第一性原理（量子力学级计算）而速度快几个数量级，是 AI for Science 里被引用最多的工具之一。

技术方案
核心思路是不再手写物理公式，而是用神经网络从量子化学计算出的数据里学出「势能面」——即给定一堆原子的位置，能量是多少、每个原子受多大力。它采用「描述符 + 神经网络」的架构：先把每个原子周围的局部环境编码成满足平移、旋转、置换不变性的特征，再让网络预测原子能量并求和得到总能量，力则由能量对位置的导数自动得到。相比传统 MD 用的经验势（如 Lennard-Jones，靠人工调参、精度有限），它精度可对标 DFT（密度泛函理论，一种量子力学近似算法）；相比直接跑 DFT 做 MD，它把单步能量与力的计算从小时/分钟级压到毫秒级。
关键数据
未披露具体数字（该条目仅为 GitHub 项目简介）。相对意义：DeepMD-kit 是 DeepModeling 社区的开源旗舰项目，已被广泛用于金属、半导体、水、合金等体系的百万原子级模拟，是「用机器学习势替代 DFT 做大规模 MD」这一路线的代表性实现。
为什么值得关注
对关心分子动力学、材料设计、药物发现和科学机器学习的读者，这是「AI 学势函数」方向最成熟的开源基础设施之一：想跑大规模、长时程的原子级模拟又不想付 DFT 的算力代价，可以直接拿它上手。

Improving synthesis prediction of small molecules at scale with RetroChimera

8 MS Research 药物发现
drug-discoverymaterialsfoundation-model

微软研究院在《Nature》发文推出 RetroChimera，用预测模型加速小分子化学合成路线设计，让药物、材料、农业领域的定制分子从「能做但慢且贵」走向可规模化探索。

技术方案
RetroChimera 做的是逆合成预测：给定一个目标小分子，反推可以用哪些反应物和反应步骤把它合成出来。相比传统逆合成工具通常只在单一或小规模数据集上训练、面对新反应类型容易失效，RetroChimera 强调「大规模」——用更大规模、更多样的化学反应数据训练，从而在更广的分子空间里给出可行合成路径。目标不是替代实验，而是帮研究者在动手做实验前先筛出值得尝试的路线，降低试错成本。
关键数据
未披露具体数字（如 top-k 准确率、覆盖的反应类型数、推理速度或训练规模）。其相对意义在于：论文登上《Nature》，且明确以「at scale（规模化）」为卖点，说明其价值主要体现在可处理的分子/反应空间范围，而非单点指标的小幅提升。
为什么值得关注
对关注 drug discovery（药物发现）、materials design（材料设计）和 scientific machine learning 的读者来说，合成可行性往往是 AI 生成分子之后的瓶颈环节；RetroChimera 这类逆合成模型直接决定「AI 设计出的分子能不能真的做出来」，是 AI for Science 从预测走向实验闭环的关键一环。

技术方案
逆合成（retrosynthesis）指从目标分子反推可用原料的合成路线。作者没有只训练一个最强模型，而是训练一组归纳偏好各异的模型——例如有的偏向局部官能团变换、有的偏向全局骨架拆分——再把这些模型的预测集成起来排序。关键设计是让集成结果与化学家人工判断的路线对齐，而不是单纯拟合反应数据库里的单步反应。相比过去依赖单一架构或单一数据分布的做法，这种「多样性集成」减少了模型在陌生反应类型上的系统性偏差。
关键数据
未披露具体数值（摘要页未给出准确率、Top-k 命中率或 benchmark 分数）。其相对意义在于：论文标题强调「chemist-aligned（与化学家对齐）」，说明评价维度从传统单步反应预测准确率，转向整条路线的化学合理性与可执行性。
为什么值得关注

Diff-NekRS: A Scalable Differentiable Framework for Multi-Timestep Solver-in-the-Loop Training

8 arXiv · 物化 分子模拟
pdescientific machine-learningcodemolecular-dynamics

把可微分训练直接嵌进 GPU 加速的 NekRS 流体求解器，让神经网络修正项能跨多个时间步做「求解器在环」训练，并在千级 MPI 进程下验证了梯度的正确性与可扩展性。

技术方案
核心是在 NekRS（GPU 加速的不可压缩流体求解器）里嵌入可训练的神经网络修正项，用来弥补粗网格模拟的误差。难点在于生产级求解器通常不提供反向传播所需的导数，作者手工实现了精确的离散伴随（adjoint，即反向求导）来微分完整时间步，再用 LibTorch 提供神经网络的向量-雅可比积和参数梯度。这样就能做多时间步的自回归 rollout 训练，而不是只优化单步。与过去只做单步或无法穿透求解器的做法不同，它把求解器前向轨迹和神经网络梯度真正打通，并用泰勒展开和中心有限差分测试验证了梯度。
关键数据
在 2D 圆柱绕流和三维 Taylor-Green 涡两个算例、5 种时间跨度、12 到 1020 个 MPI 进程上验证梯度。1020 进程时，开启优化器的训练更新仍保持 54.5%-78.0%（2Dcyl）和 80.7%-81.9%（3DTGV）的弱扩展效率。200 步自回归推理中，M=50 模型相比未修正的粗网格 P=2 基线，三种子中位数终端相对 L2 速度误差分别降低 59.2%（2Dcyl）和 12.1%（3DTGV）；相比对应 P=7 高阶配置，在相同模拟时间下仍保持 5.38 倍和 2.49 倍的实际加速。
为什么值得关注
这条直接对应 scientific machine learning 与 PDE（偏微分方程）求解方向：它解决的是「物理求解器 + 神经网络」混合方法里长期存在的可微分训练难题，对气候建模、流体仿真等需要长时间 rollout 的场景有参考价值，也展示了 AI 修正项在保持精度同时换取计算加速的量化证据。

对关心气候建模、AI for Science和科学机器学习的读者来说，这条展示了生成式ML如何把粗糙的GCM输出变成高分辨率、物理一致的数据集，直接服务于气候临界事件的影响评估，是AI4S在气候领域落地的典型样本。

ECENet: An Edge Cluster Expansion Line-Graph Neural Network

8 arXiv · 物化 分子模拟
materialsmolecular-dynamicsfoundation-modelcode

把等变图神经网络的表示中心从「原子」搬到「原子间的边」上，用更便宜的 O(2) 对称性替代 O(3)，在保持精度的同时压低计算成本，为机器学习原子间势（MLIP，用神经网络拟合原子间受力与能量）提供了一条新的效率路线。

技术方案
作者提出 edge cluster expansion（ECE，边簇展开），把传统原子簇展开的展开中心从单个原子换成原子对之间的「边」，再据此搭建线图神经网络 ECENet。ECENet 的特征是 O(2)-等变的，即只对绕键轴的旋转保持等变，而不是像主流模型那样要求完整的 O(3) 旋转等变；O(2) 操作更便宜、约束更少，因此计算开销更低。模型还通过 latent Ewald summation（隐式埃瓦尔德求和，一种处理长程静电相互作用的方法）引入长程静电，使其能预测分子偶极矩和液态水的红外光谱。
关键数据
在 MD22（分子动力学基准数据集）上达到当前最优水平；在 SPICE-MACE-OFF 数据集上训练后位于精度-成本帕累托前沿（即同等精度下成本更低，或同等成本下精度更高）。长程静电加持下可准确预测分子偶极矩与液态水红外光谱。具体推理速度、参数量、训练成本等数字未披露。
为什么值得关注
对关心分子动力学、材料设计、药物发现和科学机器学习的读者来说，MLIP 的精度与速度直接决定模拟能跑多大体系、多长时间；这条把等变表示从原子搬到边上并降阶到 O(2)，是「用更少算力换同等精度」的路线，可能影响后续势函数模型的架构选择。

Equivariant Neural Prediction of the Stokes Resistance Tensors for Arbitrary Microparticle Shapes

8 arXiv · 物化 分子模拟
molecular-dynamicsmaterialsequivariantcode

用 SO(3) 等变神经网络直接预测微粒子的完整 6x6 Stokes 阻力张量（而非压缩成单个标量），精度达 1.4%/2.7%，速度比传统数值求解器快 4-5 个数量级。

技术方案
把粒子表面用球谐函数（球面形状的频谱表示）描述，输入一个对旋转等变的神经网络，直接输出阻力矩阵中的平移块 A 和旋转块 C，且输出天然对称正定、等变精度到浮点级别。训练集为 1.1×10^5 个从近球形到极粗糙的随机形状，标签由正则化 Stokeslet 求解器生成，另留 18,000 个密封测试形状。与过去把阻力压缩成单个标量（丢掉方向依赖和旋转响应）的经验关联式不同，它保留了完整的各向异性张量信息。
关键数据
两个张量块的平均相对误差分别为 1.4% 和 2.7%；单形状推理比生成标签的 Stokeslet 求解器快 4-5 个数量级。球谐截断到 15 阶时，平移和旋转阻力中位变化仅 0.14% 和 0.38%。在 1.16×10^6 次取向采样事件中，代理模型揭示出最大 11° 的横向漂移、46° 的旋转失配，以及形状诱导扩散展宽：平移 30%、旋转 2.4 倍——这些在标量或椭球近似下全为零。传统关联式给出的取向平均标量摩擦精度为 1.7-2.8%（中位）和 2.2-3.2%（均值），代理模型在复现该标量到约 1% 的同时还能给出完整各向异性张量。
为什么值得关注
对做科学机器学习、PDE（偏微分方程）代理模型和分子/胶体动力学的读者，这是一个「等变网络替代传统数值求解器」的干净案例：既展示了几何深度学习如何嵌入物理对称性，也直接服务于大气尘埃输运、微塑料归趋和胶体布朗动力学等 AI for Science 场景。

SPIBER: Reconstructing Free Energy Landscapes from Short, Unconverged Trajectories with Generative Flow Networks

8 arXiv · 物化 分子模拟
molecular-dynamicsfoundation-modelcode

把「找慢变量」和「算自由能」合成一套流程，只用多段互不连通的短模拟轨迹，就能把亚稳态之间的自由能差算到约 1 个热能单位以内，且不需要轨迹收敛或补跑分子动力学。

技术方案
先用 SPIB（状态预测信息瓶颈，一种深度学习降维方法）从轨迹中提取少数几个「慢变量」——即决定体系长期行为的关键坐标，最多 4 维。作者发现这种压缩会限制已采样区域内的条件熵变化，于是可以用更容易算的「条件平均势能」来近似自由能差。再把这些能量定义成目标分布，交给 GFlowNets（生成流网络，一种按能量而非出现频率采样的生成模型）去采样，从而绕开「短轨迹里各状态出现次数不代表其真实稳定性」这个老问题。相比直方图重加权等传统方法（在单温度、无偏采样下无法修正状态间布居失衡），它不依赖收敛的布居数，也不用额外跑模拟。
关键数据
在三个体系上验证：径向双势阱中的单粒子、丙氨酸二肽（alanine dipeptide）、九残基肽 AIB9。恢复的亚稳态间自由能差与参考值相差在 1 个热能单位（kT）以内；潜变量维度最多 4 维；无需收敛的态布居，也无需额外分子动力学模拟。
为什么值得关注
对做分子动力学、自由能计算和药物发现的读者来说，它针对的是「短轨迹不收敛、状态间布居不可信」这一常见痛点，提供了一条不补跑模拟就能估自由能的路子，属于科学机器学习与 MD 交叉的实用方向。

技术方案
PepMimic 的核心思路是「界面模仿」：先看目标蛋白上某段天然结合界面长什么样，再设计一条短肽去复刻这个界面的关键接触残基和空间构象，而不是像过去那样从随机序列出发做大规模筛选或纯序列生成。这样做的好处是把「能不能结合」这个最难的问题，转化为「能不能模仿一个已知能结合的界面」这个更容易约束的问题，设计空间更小、命中率更高。仓库是该论文的官方实现，包含模型与设计流程代码。
关键数据
未披露（该条目仅为论文被接收与代码开源的信息，摘要中未给出亲和力、成功率等具体数字；其意义在于方法被 Nature Biomedical Engineering 接收，说明界面模仿路线获得了同行评审认可）。

SciML/LinearSolve.jl

7 GitHub · SciML 科学基础模型
scientific machine learningpdecode

把 Julia 生态里各种线性求解器（分解法、Krylov 迭代法）统一到一个接口下，换算法、加预条件子只需改一行，省去重写代码的麻烦。

技术方案
LinearSolve.jl 定义了一套公共 API，用户用同一个 solve 调用就能在直接分解（LU、Cholesky 等）和迭代法（Krylov 类，如 GMRES、CG）之间切换，并可挂接预条件子。它把这些求解器包成统一抽象层，而不是让用户直接调用底层库各自的接口。相比过去每个求解器一套调用方式、换方法要改大量代码，它把「选算法」变成可配置项，方便做基准对比和自动调参。
关键数据
未披露具体加速数字或 benchmark 分数；其价值在于接口统一带来的工程效率，而非单点性能提升。
为什么值得关注
线性求解是科学计算的核心步骤，PDE（偏微分方程）数值解、分子动力学、材料模拟、气候建模都依赖它；对做 scientific machine learning 的读者，统一接口意味着换求解器、试预条件子更快，便于把求解器嵌入可微分或代理模型流程。
